# 世界模型读写协议

### 不同的本地文件或传感器 
- 地图数据
- 里程计
- 雷达
- AMCL精度校准


## 各个数据块
| 数据块 |  唯一写者 | 默认值（降级行为） |
|---|---|---|
|odom_x/y/yaw| main OdomCallback    |0, 0, 0|
|corr_x/y/yaw + corr_valid|	main AmclCallback   |误差为0|
|pose_x/y/yaw, scan_angle_forward   |UpdatePosition   |	同上退化|
|scan_ranges/角度 + scan_valid   |main ScanCallback   |	雷达波值inf|
|地图块 map_*   |LoadMap 或内置   |内置空旷图 = A 走直线*|
|dyn_cells/stamp/version   |UpdateDynamicLayer(事件驱动)   |全 0 = 无动态标记|
|cmd_v/w   |技能层   |	0 = 停
